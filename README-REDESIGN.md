- Replaced the homepage with a recruiter-focused construction planning profile.
- Standardized About, Expertise, and Experience pages.
- Added a project gallery and SiteHercules case-study page.

- Retained the existing Resume PDF path and known public project links.

## Before merging
- Check all employment details, dates, project descriptions, and links against your current CV.
- Add actual project screenshots only when disclosure is permitted.
- Confirm the live AppSheet app's access settings; the old homepage displayed demo credentials, which have intentionally been removed.
- Consider replacing remote decorative images with approved local images.
- Test mobile navigation, CV download, external links, and GitHub Pages deployment.

No new performance claims or project outcomes have been invented. The SiteHercules case-study page marks details that need your own evidence.
